# Tasca 2: Git, viatjant pel temps

## Descripció

En aquesta activitat s'ha treballat amb el sistema de control de versions Git i la plataforma GitHub, aprenent a gestionar l'historial d'un repositori i recuperar versions anteriors dels fitxers.

## Objectius

- Aprendre a crear commits amb missatges descriptius.
- Consultar i interpretar l'historial de commits.
- Identificar els canvis realitzats en cada versió.
- Recuperar versions anteriors dels fitxers.
- Utilitzar les ordres `git restore`, `git revert` i `git reset`.
- Documentar els procediments mitjançant Markdown.

## Contingut

Aquest directori conté:

- `README.md`: presentació i descripció de l'activitat.
- `solucions.md`: documentació dels exercicis pràctics realitzats.
- `img/`: captures de pantalla que mostren els procediments i resultats obtinguts.
